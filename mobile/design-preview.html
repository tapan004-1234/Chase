Game State — Tag Mode (Dual-Role Color System)
Tag mode has two roles: Police (P) and Thief (T). The same event shows different colors depending on your role — catching the thief is blue for police, red for the thief. Color encodes both role and outcome.

Motion System
Game State Change
80–120ms · CUT
The snap IS the point. It mimics the moment something crosses you. Applies to both Ghost proximity states and Tag mode busted/escape moments.
Screen Transitions
150–250ms · ease-out
Enter on ease-out, exit on ease-in. Never slow. This is a running app.
Live Data Numbers
No animation
Pace, distance, delta update instantly. Animated live data creates perceived lag at speed.
Map Route Draw
Real-time append
Route extends as you run. Ghost route shown as-is. No animated redraw — the trail is a record, not a presentation.

Stats Screen
Period filter uses underline-active pattern (not pill). Chart: bar columns (blue, low opacity) + line sparkline overlay + chartreuse endpoint dot. KM total in Barlow Condensed 900 — same weight as the run screen hero numbers. Rating shown in chartreuse (your data = your color).
Profile Screen
Rival result dot: green square = winning record vs that opponent, red square = losing record. Two-mode rating tiles (Tag red / Ghost blue) reinforce the role-color system. History tab badge shows total games, not active count — it's a record, not a notification.
